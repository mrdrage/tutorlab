# Generation Coverage v0.4

## Scope

This block makes every year-3 Mathematics and English curriculum node executable by the Session Engine.

Mathematics coverage includes signed numbers, rational expressions, real-number classification, symbolic generalisation, algebraic expressions, first-degree equations, multiple representations, elementary function families, circle geometry, Euclid theorems, solids, surface area, volume, probability, tool selection, algorithmic thinking and integrated problem solving.

English coverage completes the A2-oriented graph across grammar, vocabulary, phonology, reading, listening, interaction, spoken production, writing, mediation, intercultural work and learning strategies. Extension grammar remains optional for A2 mastery.

## Quality rules

A curriculum node is covered only when all five adaptive actions build successfully: recover, consolidate, advance, extend and reassess. Every generated session must pass the existing quality gate.

Open language tasks carry a rubric and an explicit scoring target. Listening tasks may carry a tutor-side script that is removed from the learner-facing view.

## Full-triennium invariant

The cumulative checker validates all six curriculum files for years 1, 2 and 3. After this block, every Mathematics and English node in the supported middle-school scope must be present in the generation registry and must build valid sessions.

Requests outside the supported curriculum continue to return needs_review rather than being generated ad hoc.
