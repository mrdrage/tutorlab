# Spagnolo — curriculum middle school v0.6

Curriculum TutorLab per la scuola secondaria di primo grado.

- nodi complessivi: 46
- anni: 1ª, 2ª, 3ª
- traguardo: A1 QCER
- `typical_year` descrive una sequenza pedagogica interna TutorLab, non una scansione ministeriale obbligatoria.
- i prerequisiti possono attraversare gli anni e il motore deve ritornare all'obiettivo sospeso dopo un recupero.
- ogni nodo contiene obiettivi, evidenze di padronanza, segnali diagnostici e leve di difficoltà.

La generation coverage è verificata localmente con `tools/check_language_expansion.py`. Nessun GitHub Workflow è richiesto.
