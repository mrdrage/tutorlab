# Mappa tutor — Inglese 1ª-3ª media

Questa vista riassume le principali arterie del grafo. I prerequisiti effettivi restano nei file JSON.

## Sistemi linguistici

### Grammatica

`be → Present Simple → domande di base → Past Simple → piani futuri → forme A2`

Percorsi paralleli:

- `Present Continuous → going to / accordi futuri`
- `can → should / obbligo e necessità`
- `Past Simple → Present Perfect per esperienze`
- `frase semplice → connettivi → testo connesso`

Le strutture passive e il reported speech semplice sono marcati come **extension**: possono essere utili in terza, ma non sono trattati come requisiti necessari per dimostrare A2.

### Lessico

1ª media: identità, famiglia, scuola, routine, casa, città, tempo libero, cibo.

2ª media: viaggi, acquisti, salute, luoghi e ambiente.

3ª media: lavoro e futuro, tecnologia/media, ambiente globale, cultura/viaggio, emozioni e relazioni.

### Fonologia

`alfabeto e spelling → word stress → -ed e sentence stress → connected speech e intonazione`

## Reception

### Reading

`testi personali brevi → testi multipli / narrazioni → testi quotidiani A2 → articoli, biografie, istruzioni → strategie task A1/A2`

### Listening

`informazioni personali → istruzioni quotidiane → annunci / racconti → conversazioni A2 → interviste e contenuti informativi → strategie task A1/A2`

## Interaction

`presentarsi → routine e preferenze → acquisti / viaggio / inviti / salute → opinioni → pianificazione e problem solving → servizi e interazione online`

## Production

### Spoken

`descrivere sé e routine → raccontare un evento → confrontare e parlare di piani → esperienza/futuro/opinione → breve presentazione`

### Writing

`moduli e messaggi → paragrafo personale → email / narrazione → email A2 / narrazione A2 / opinione`

## Mediation

`riferire informazioni semplici → selezionare punti essenziali → riferire informazioni specifiche → spiegare testo o dati semplici → costruire significato in collaborazione`

## Strategie

`chiedere chiarimento → distinguere gist e detail → prendere note essenziali → parafrasare una parola mancante → autovalutarsi con evidenze can-do`

## Diagnosi rapida

Se un ragazzo fallisce un compito, TutorLab non deve concludere subito che “non sa l'inglese”. Deve localizzare il collo di bottiglia:

- sistema linguistico;
- lessico;
- riconoscimento fonologico;
- strategia di comprensione;
- organizzazione del testo;
- gestione dell'interazione;
- capacità di riparare la comunicazione.

Questa distinzione guida il recupero mirato.
