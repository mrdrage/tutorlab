# Acceptance tests: Learning Snapshot v0.1

Il macro-blocco e accettato quando:

1. un objective stack attivo viene ripreso prima di scegliere un nuovo target;
2. un target esplicito resta root target anche durante un recupero;
3. un prerequisito debole puo diventare working target temporaneo;
4. un prerequisito senza evidenze sufficienti non viene trattato come errore certo;
5. uno stato developing non avanza se non soddisfa le soglie multidimensionali;
6. il completamento di un recupero sicuro riporta all'obiettivo sospeso;
7. una competenza senza task family produce needs_review invece di una sessione inventata;
8. una sessione completata genera evidence events;
9. lo snapshot aggiornato conserva session id e fingerprint recenti;
10. i fingerprint recenti evitano la ripetizione immediata della stessa variante;
11. matematica e inglese attraversano lo stesso kernel di pianificazione;
12. nessun modulo del core dipende da UI, database o Hub Scuola.

Le verifiche automatiche usano esclusivamente fixture sintetiche generate nel repository.
